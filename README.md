# Portfolio Site

My personal portfolio website built with **Astro** and deployed on
**Netlify**.

The site showcases my work, technical skills, and selected projects,
with a focus on modern frontend development, performance, and clean user
experience.

## Tech Stack

- Astro
- TypeScript
- Tailwind CSS
- Netlify

## Features

- Responsive design
- Fast static site generation
- Project showcase
- About & experience sections
- Contact information
- SEO-friendly structure

## Live Website

**https://sonpeter.com**

## Local Development

```bash
npm install
npm run dev
```

Build for production:

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```

## Project Structure

```text

  components/
  layouts/
  pages/

```
